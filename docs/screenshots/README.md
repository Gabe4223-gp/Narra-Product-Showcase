# Screenshots

Images referenced by the main README. Save them here with these exact names:

| File | Shows |
|---|---|
| `properties.png` | Manager dashboard — the Properties list |
| `billing.png` | Billing — Unfulfilled and Fulfilled bills |
| `tenant-profile.png` | Tenant profile — details, billing activity, leases, actions |
| `work-portal.png` | Work Portal — map with nearby maintenance workers |

PNG or JPG both work; keep each under about 1 MB so the repository stays small.

Before saving, check the images for anything you would not want public: real
tenant names, email addresses, phone numbers or bank details. The demo data is
fictional, but screenshots taken while signed in can capture your own account
name in the header.
